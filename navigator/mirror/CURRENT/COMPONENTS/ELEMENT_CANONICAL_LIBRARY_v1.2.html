Nine verbs applied

Orient

Locate the reference, source, Context and authority question.

Canonicalise

Resolve identity and state; promotion remains an authorised act.

Structure

Bind definition, scope, version, relationships and evidence.

Assure

Test conflicts, provenance, completeness and permitted use.

Navigate

Route users to the current authorised reference and its evidence.

Compose

Use canonical references as constraints in Methods, Services and Work Objects.

Activate

Permit use only within the recorded authority and state.

Transform

Supersede or revise a reference with lineage preserved.

Project

Show promoted, candidate, conflicted, insufficient and historical states without implying mutation.

Mesh integration

Entry

A signal or governed need enters with identity, Context and source.

Validation

Evidence, MECE, authority, PPV and readiness are tested.

Action

Only an authorised expression may change governed work.

Observation

Effects, exceptions and source receipts are recorded.

Asset conversion

Reusable value is proposed only after repeated evidence.

Feedback

Learning returns to the owning element and current Work Object.

Cross-element MECE ownership

Owns

Definition identity, scope, version, authority and canon state.

Does not own

Method procedure, Pattern recurrence, Service offering, Work Object execution, Benefit claim or Asset qualification.

Integration contract

Every relationship names the owning element, referenced object, evidence route and authority state; shared relationships are explicit, never duplicate ownership.

Design-instance inventory

Enough instance identity and relationships are shown for design, integration and stress testing. Mutable operational fields, transactions, performance and runtime configuration remain in Odoo/N8N.
