Nine verbs applied

Orient

Classify the task, evidence need, risk and required capability.

Canonicalise

Resolve agent identity, lane mandate and current control references.

Structure

Bind prompt, sources, Work Object, acceptance, permissions and return path.

Assure

Test separation of duties, credentials, evidence and replay safety.

Navigate

Select D008, Navigator, Claude, Codex, D009, D001 or D007 lane.

Compose

Coordinate multiple lanes without merging authority or assurance.

Activate

Release execution only through the authorised D007/runtime path.

Transform

Update routing and prompts from observed outcomes.

Project

Show lane status, dependencies, holds and receipts.

Mesh integration

Entry

A signal or governed need enters with identity, Context and source.

Validation

Evidence, MECE, authority, PPV and readiness are tested.

Action

Only an authorised expression may change governed work.

Observation

Effects, exceptions and source receipts are recorded.

Asset conversion

Reusable value is proposed only after repeated evidence.

Feedback

Learning returns to the owning element and current Work Object.

Cross-element MECE ownership

Owns

Lane mandate, routing decision, permissions, separation of duties, runtime release path and return receipt.

Does not own

Enterprise authority itself, Service/Method/Pattern identity, Benefit claims, Asset qualification or operational register truth.

Integration contract

Every relationship names the owning element, referenced object, evidence route and authority state; shared relationships are explicit, never duplicate ownership.

Design-instance inventory

Enough instance identity and relationships are shown for design, integration and stress testing. Mutable operational fields, transactions, performance and runtime configuration remain in Odoo/N8N.
