Nine verbs applied

Orient

Identify the bounded environment, actors, purpose and current conditions.

Canonicalise

Resolve Context identity and authoritative boundary definitions.

Structure

Define membrane rules, allowed objects, relationships and evidence sources.

Assure

Test permissions, conflicts, privacy, risk and source-account integrity.

Navigate

Route work and information through permitted crossings.

Compose

Combine enterprise elements into a Context-specific expression.

Activate

Permit a crossing or action only under recorded authority.

Transform

Change the boundary or local capability from observed evidence.

Project

Show current, candidate, stale and historical Context states.

Mesh integration

Entry

A signal or governed need enters with identity, Context and source.

Validation

Evidence, MECE, authority, PPV and readiness are tested.

Action

Only an authorised expression may change governed work.

Observation

Effects, exceptions and source receipts are recorded.

Asset conversion

Reusable value is proposed only after repeated evidence.

Feedback

Learning returns to the owning element and current Work Object.

Cross-element MECE ownership

Owns

Context identity, boundary, actors, permissions, exclusions and membrane crossing rules.

Does not own

Service definition, Method steps, canonical state, Benefit claim, Asset maturity, Work Object priority or runtime execution.

Integration contract

Every relationship names the owning element, referenced object, evidence route and authority state; shared relationships are explicit, never duplicate ownership.

Design-instance inventory

Enough instance identity and relationships are shown for design, integration and stress testing. Mutable operational fields, transactions, performance and runtime configuration remain in Odoo/N8N.
