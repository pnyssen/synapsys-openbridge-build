Nine verbs applied

Orient

Locate the Work Object in the lifecycle and identify the blocking gate.

Canonicalise

Resolve object identities and governing references before movement.

Structure

Assemble stage inputs, relationships, owner and acceptance tests.

Assure

Validate evidence, authority, risk, PPV and readiness.

Navigate

Select the next valid stage and return route.

Compose

Combine required Services, Methods, Patterns and controls.

Activate

Release one authorised action; HOLD otherwise.

Transform

Convert observations into changed capability or design.

Project

Show current stage, gates, exceptions and feedback state.

Mesh integration

Entry

A signal or governed need enters with identity, Context and source.

Validation

Evidence, MECE, authority, PPV and readiness are tested.

Action

Only an authorised expression may change governed work.

Observation

Effects, exceptions and source receipts are recorded.

Asset conversion

Reusable value is proposed only after repeated evidence.

Feedback

Learning returns to the owning element and current Work Object.

Cross-element MECE ownership

Owns

Lifecycle stage, transition criteria, gate result, STOP/HOLD and feedback route.

Does not own

Element identity, Service definition, Method procedure, Benefit measure, Asset qualification decision or runtime authorisation.

Integration contract

Every relationship names the owning element, referenced object, evidence route and authority state; shared relationships are explicit, never duplicate ownership.

Design-instance inventory

Enough instance identity and relationships are shown for design, integration and stress testing. Mutable operational fields, transactions, performance and runtime configuration remain in Odoo/N8N.
