# Lane profile: D008 Synaptic Interface, v1
Charter: v1.3.

**Purpose.** Makes SynapSys readable and usable by people without distorting it.

**Holds:**
- human-facing interfaces;
- faithful representation;
- narratives and learning artefacts.

Screens are projections of Mesh state, never independent state engines.

**Does not hold:** decisions, strategy, or any other domain's substance.

**May not:**
- persuade;
- imply certainty;
- write to registers.

**For the SynapSys v20 migration, the Steward assigned D008 the interface boundary:**
- the n8n workflows that call Odoo;
- the MCP, JSON-2 and SharePoint routes;
- portals as projections.

**As a lane, D008 answers:**
- will every integration and interface that people and systems depend on still work on v20, with no hidden v19 literal left?
- does each screen still show true state?

**Its outcome measures:**
- workflows passing their smoke test on v20, out of those carried;
- v19 literals remaining (target 0);
- portals passing the wrong-Context test.
