# Overnight Stream B — Inversion and Deletion Log v0.1

Per the dispatch's step 6 ("Inversion and critical challenge"): identify how
the generated suite could create another competing control surface,
misstate operational truth, hide authority, confuse candidate/current
states, or overload the Steward — then delete or fix, and add a regression
test for each. Every row below either resulted in a concrete deletion/fix
(with the test that guards it) or a documented reason no change was needed.

## Deletions made (summary)

- A candidate standalone Overnight dashboard HTML (never built).
- A second, duplicated compiler code path for SCVS rendering (never built; single wrapper used instead).
- The vestigial copy-to-clipboard `packets` script from the v1.3 candidate (present, unused, in the v1.2 reference capture — removed).
- A tempting "example Stream A payload" fixture that would have blurred the "no fabrication" boundary (never built).

## Not deleted, disclosed instead

- The three `COMPONENTS/*.html` iframe `src` paths — vault-relative by original v1.2 design; kept, not silently claimed to be portable, allow-listed by name in the link test, and called out in `README.md`.
